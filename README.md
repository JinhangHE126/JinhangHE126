### 🧬 About Me

Hi, I'm **Jinhang (Caelum) He**.

I am an AI Developer based in Hong Kong, building production LLM apps, RAG systems, and multi-agent platforms. My focus is reliability in the real world: grounded answers, traceable evidence, and agent loops that fail safely.

I have delivered a privatized medical RAG Q&A system under NDA, built AlphaPilot for multi-agent equity research, and contributed merged PRs to an open-source LangGraph starter kit. I work across the stack — LangGraph orchestration, FastAPI backends, and React frontends — with Python, TypeScript, PyTorch, and Docker.

MSc Data Science & AI graduate from The Hang Seng University of Hong Kong. Currently an AI Developer at **Epro Telecom Services**, and open to **AI Engineer / AI Agent Engineer / RAG Engineer** roles.

### 🚀 Selected Projects

* **AlphaPilot** — LangGraph multi-agent equity research platform (HK & US) with Evidence Packet, hybrid RAG, and Bull vs Bear debate with field-level citations. ([Repo](https://github.com/JinhangHE126/Alphapilot))
* **Medical RAG Q&A (NDA)** — Privatized multi-site clinical Q&A: ASR → hybrid retrieval → cited answers, with LangGraph quality gates and on-prem isolation.
* **Quadruped Robot Control** — Real-time pedestrian-following for Unitree Go2 (Jetson Nano): YOLOv8 (ONNX) + KCF tracking, ROS Catkin + Unitree SDK. ([Repo](https://github.com/JinhangHE126/Pedestrian-detection))

### 🧬 关于我

你好，我是 **何金航（Caelum）**。

我是一名常驻香港的 AI Developer，专注打造可落地的大模型应用、RAG 系统与多智能体平台。我更在意真实场景下的可靠性：有据可依的回答、可追溯的证据，以及能安全失败、可审计的 agent 流程。

毕业于香港恒生大学数据科学与人工智能硕士。目前在 **Epro Telecom Services** 担任 AI Developer，同时开放 **AI Engineer / AI Agent Engineer / RAG Engineer** 相关机会。
