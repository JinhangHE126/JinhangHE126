### 🧬 About Me

Hi, I'm **Jinhang (Caelum) He**.

I am an AI Developer based in Hong Kong, building production LLM apps, RAG systems, and multi-agent platforms. My focus is reliability in the real world: grounded answers, traceable evidence, and agent loops that fail safely.

I have delivered a privatized medical RAG Q&A system under NDA, built AlphaPilot for multi-agent equity research, and contributed merged PRs to an open-source LangGraph starter kit. I work across the stack — LangGraph orchestration, FastAPI backends, and React frontends — with Python, TypeScript, PyTorch, and Docker.

MSc Data Science & AI graduate from The Hang Seng University of Hong Kong. Currently an AI Developer at **Epro Telecom Services**, and open to **AI Engineer / AI Agent Engineer / RAG Engineer** roles.
